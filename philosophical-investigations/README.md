# 《哲学研究》中文逐节阅读

本目录为 BookBook 书库中的独立书籍页面，覆盖第一部第 1—250 节。

每节提供中文学习自译、核心结论、文句精读、概念拆解、论证分析、不同视角与误读辨析。精读引句全部使用中文，不提供德文切换。中文自译和解释尚未经专业审校。

中文页面以霞鹜文楷排版，主色为 #CC7D5E，支持手机、深色模式、大字号、分组目录和节号跳转。

部署和预览请在仓库根目录运行 `npm run check`、`npm run build`、`npm run dev`。本书随书库统一发布。

`content.js`、`essays.js` 保存前十节；`data/` 保存第 11—250 节及复核增补；`index.html` 声明加载顺序。`sources/` 与 `originals.js` 保留底本供离线校对。字体和图示来源见各自资源目录的说明与许可。

第 101—250 节每节解释至少包含 2,000 个汉字，提供至少四条中文文句精读。内容检查分别验证节次、结构和解释篇幅；篇幅检查不能替代译文与论证的人工审校。

修改文本后可使用 `scripts/subset-font.py` 重新生成字体子集。完整原始字体需按字体来源说明另行取得，不纳入 Git 提交。
