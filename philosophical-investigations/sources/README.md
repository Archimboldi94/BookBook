- [来源项目的 Markdown 文件](https://github.com/wittgenstein-project/wittgenstein-project.github.io/blob/main/markdown/german/Philosophische%20Untersuchungen/Philosophische%20Untersuchungen.md)
- 数字版编辑说明：据 Suhrkamp 1999 年《著作集》第 1 卷，第 231—485 页。
- 核对日期：2026-11-12。

来源页将德文作品标为在原属国以及实行作者逝世后 70 年或更短保护期的地区进入公有领域，不代表所有地区的状态相同。本站没有复制现有中文出版译文。

`sections-1-350.md` 保存所用德文，`originals.js` 是仅供离线校对的相同段落数据。只统一段落间隔、去除 Markdown 强调标记，不改写德文；第 1 节保留拉丁文引文。

第 48 节的位置编号图、色块图，以及第 86 节的两幅读取路径图、第 166 节的陌生符号图和第 216 节的斑块图保存在 `assets/originals/`。图示文件直接取自同一底本资源目录，网页不将 Markdown 图片标记当成正文显示。

中文为本站基于德文制作的 AI 辅助学习自译，未经专业译者审校。第 1 节奥古斯丁引文根据所附德译转译。讲解、标题、例子和对照表为本站编写，应当与原文区分。中文自译和解释适合初学辅助，不能替代校勘本与专业译本。

如要重新获取原文：将上面来源 Markdown 下载为 `sources/original.md`，在项目目录执行 `node scripts/extract-originals.mjs`。该脚本只提取第 1—350 节，下载的整本源文件被 Git 忽略。
